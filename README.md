# 🚀 NebiusXTeam - Frontend

An interactive multi-agent coding assistant frontend built for the **Nebius NVIDIA Hackathon**.

---

## 📌 Project Overview
This project provides a clean and modern user interface for real-time interaction with AI coding agents. Users can input tasks/code and observe live status updates, generated code, security audits, testing results, and performance findings.

---

## 🛠️ Features
- **Modern Dark UI:** Tailored with NVIDIA-inspired styling for high readability.
- **Agent Dashboard:** Displays real-time status updates from backend multi-agent workflows.
- **Task Input & Trigger:** Interactive controls to submit tasks directly to the agents.

---

## 💻 Tech Stack
- **HTML5** - Page structure
- **CSS3** - Custom UI styling and layout design
- **JavaScript (ES6+)** - Dynamic DOM updates and core UI interactions
